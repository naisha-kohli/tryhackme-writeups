# Windows Fundamentals — Windows Update & Windows Security

## Windows Update

Windows Update keeps the operating system secure and up to date.

### Patch Tuesday
- Microsoft usually releases security updates on the **second Tuesday of every month**.
- This is commonly known as **Patch Tuesday**.
- If a vulnerability is critical, Microsoft may release an update immediately without waiting for Patch Tuesday.

### Open Windows Update
Run the following command from **Run (Win + R)** or **Command Prompt**:

```cmd
control /name Microsoft.WindowsUpdate
```

### What you can access
- Check for updates
- Restart if required
- View update history
- Advanced options
- Manage update settings

# Windows Security

Windows Security is the built-in protection center for Windows.

### Main Protection Areas
- **Virus & threat protection**
- **Firewall & network protection**
- **App & browser control**
- **Device security**

### Security Status Colors
- 🟢 **Green:** Protected, no action needed.
- 🟡 **Yellow:** Review recommended security actions.
- 🔴 **Red:** Immediate attention required.

Open **Windows Security** to view the protection status of your device.

# Microsoft Defender

**Microsoft Defender Antivirus** is Microsoft’s built-in antivirus that scans your computer for viruses, malware, and other threats.

You can also **right-click any file or folder → Scan with Microsoft Defender** to check if it is safe.

---

# Virus & Threat Protection

## Current Threats

### Scan Options
- **Quick Scan:** Checks the most common locations where malware is usually found.
- **Full Scan:** Scans the entire computer.
- **Custom Scan:** Scans a specific file or folder chosen by the user.

### Other Options
- **Threat History:** Shows previously detected threats.
- **Last Scan:** Displays when the most recent scan was performed.
- **Quarantined Threats:** Threats that have been isolated so they cannot harm the system.
- **Allowed Threats:** Files or programs that are permitted even if they were detected.

### Real-time Protection
Continuously checks files and programs to stop malware from installing or running.

# Windows Firewall & Security

## Firewall and Network Protection

### What is a Firewall?
A **firewall** is a security feature that monitors and controls network traffic entering and leaving your computer through **ports**. It blocks unauthorized connections while allowing trusted communication.

### Firewall Profiles

| Profile | Description |
|----------|-------------|
| **Domain** | Used when your PC is connected to an organization's network and can verify its identity with the organization's server (domain controller). |
| **Private** | Used for trusted networks, such as your home or personal Wi-Fi. |
| **Public** | Used for untrusted networks like public Wi-Fi in airports, cafés, or hotels. It provides the strictest security. |

### Firewall Settings
- **Turn Firewall On/Off** – Enables or disables firewall protection.
- **Block All Incoming Connections** – Prevents other devices from starting a connection with your computer (e.g., Remote Desktop or file sharing). Your computer can still start connections to other devices.

### Windows Defender Firewall with Advanced Security
- Open using **`wf.msc`**.
- Provides advanced firewall settings for experienced users or administrators.
- Allows you to create detailed inbound/outbound rules and monitor network traffic.

# Device Security

## Core Isolation
- Uses hardware virtualization to isolate critical parts of Windows, making them harder for malware to attack.

### Memory Integrity
- Prevents malicious code from being inserted into high-security Windows processes.

## Trusted Platform Module (TPM)

- **TPM (Trusted Platform Module)** is a dedicated security chip built into the motherboard.
- It securely stores encryption keys, passwords, and other security information.
- Since the keys are stored in hardware instead of normal storage, malware cannot easily steal or modify them.

### TPM & BitLocker
- **BitLocker** encrypts your drive to protect your data if your computer is lost or stolen.
- Without BitLocker, someone could remove your SSD/HDD and read your files from another computer.
- With BitLocker enabled, the data stays encrypted and cannot be accessed without the correct authentication.
- TPM securely stores the encryption key and automatically unlocks the drive only if the computer has not been tampered with.
- BitLocker can also use:
  - **Startup Key** – A USB drive containing the unlock key.
  - **PIN** – A password entered during startup (less secure if weak).

# BitLocker

- A Windows drive encryption feature that protects your data from theft or unauthorized access.
- Encrypts the entire drive so that files remain unreadable without the correct authentication.
- Commonly used on laptops to protect data if the device is lost or stolen.

---

# Volume Shadow Copy Service (VSS)

- **Volume Shadow Copy Service (VSS)** creates a snapshot (shadow copy) of files before they are backed up.
- This allows Windows to back up files even if they are currently being used by the system or an application.
- It ensures backups remain consistent without interrupting your work.

---

# System Restore

System Restore uses restore points to return Windows to an earlier working state without affecting personal files.

### Restore Point Options
- **Create Restore Point** – Saves the current system configuration.
- **System Restore** – Restores Windows to a previously saved restore point.
- **Configure Restore Settings** – Enables/disables System Restore and manages disk space usage.
- **Delete Restore Points** – Removes existing restore points to free up storage.
